# Keeper - React Note-Taking App

A simple and elegant note-taking application built with React to learn and practice React fundamentals.

## Overview

Keeper is a lightweight note-taking app that allows users to create, view, and delete notes. This project is designed as a learning tool to understand React concepts including components, state management, hooks, and event handling.

## Features

- ✨ Create new notes with title and content
- 📝 Display notes in a clean, organized layout
- 🗑️ Delete notes with a single click
- 💾 Lightweight and fast
- 🎨 Simple and intuitive user interface

## Technologies Used

- **React** - JavaScript library for building user interfaces
- **JavaScript (ES6+)** - Modern JavaScript syntax
- **CSS** - Styling and layout
- **React Hooks** - State management with useState

## Learning Objectives

This project demonstrates:
- React functional components
- React hooks (useState, useEffect)
- Event handling in React
- Component composition
- Props passing between components
- Conditional rendering
- List rendering with keys

## Getting Started

### Prerequisites
- Node.js and npm installed on your system
- Basic understanding of JavaScript and React

### Installation

1. Clone or download the project
2. Navigate to the project directory:
   ```bash
   cd Keeper-1
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the development server:
```bash
npm start
```

The app will open in your browser at `http://localhost:3000`

## How to Use

1. **Create a Note**: Enter a title and content and click "Add"
2. **View Notes**: Your notes will appear below the input area
3. **Delete a Note**: Click the delete button on any note to remove it
